# ISITUSA Canopy

Original A–Z and a–z outlines, with broad curved strokes, crisp flared stems and open lowercase counters. Logo exports and heading type share one font master. Ancillary characters and font structure derive from Outfit 800, under SIL OFL 1.1 (included). No NYBG font or logo outlines are included.

Build: `scripts/build-brand-v8.py` with the official Google Fonts `ofl/outfit/Outfit[wght].ttf`. Requires FontTools, Brotli and skia-pathops. Render artwork with `scripts/render-brand-v8.mjs`.

Use the supplied weight 800 without synthetic bold or italic. This is a display face; retain the site's body family for paragraphs, forms and dense interface text.
