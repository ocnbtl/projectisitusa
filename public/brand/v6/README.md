# ISITUSA refined uppercase artwork

Seven custom capitals drawn together, with a 100-unit cap height, 21-unit vertical stems, optically lighter 19-unit horizontals and 2-unit curve overshoot. The S and U curves are smooth and repeat exactly; spacing is adjusted per letter pair. No font installation is required.

The name is ISITUSA: one uppercase word. Preserve the original proportions. Use green on light surfaces and white on dark surfaces. SVG masters and transparent PNGs are included. The approved v3 emblem and favicon remain unchanged.

Rebuild with `node scripts/build-brand-v6.mjs`. The wordmark viewBox is 532 x 116; the emblem lockup remains 840 x 1080. Earlier kits are historical versions.
