# About wording and typography

The v3 logo has custom image-generated lettering traced to vector paths; there is no source font to reuse. Compared Lilita One, Paytone One, and Titan One. Lilita One is the closest available match, not an exact reconstruction. Original brand artwork is unchanged.

Self-hosted original Lilita One Regular from https://raw.githubusercontent.com/google/fonts/main/ofl/lilitaone/LilitaOne-Regular.ttf with the accompanying OFL.txt license from the same directory. SIL Open Font License 1.1 permits website embedding.

Scientific collections describes the museum and herbarium records represented by existing iDigBio and GBIF sources. The attribution disclaimer is retained.

Validation: scoped diff and Impeccable detector before commit; hosted build and desktop/mobile visual verification before production promotion. No research data, contribution logic, or credentials changed.
