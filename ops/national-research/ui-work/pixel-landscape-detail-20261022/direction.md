# Detailed pixel woodland

Original artwork, created with the existing Sharp export pipeline. Revision replaces repeated crowns/rows with irregular groves, independently branching broadleaf crowns, upright smaller trees, two conifer branching patterns, distant slope forest, low fern/grass detail, and multiple rugged ridges with face and contour shading. Separate desktop 1800x500 and mobile 640x420 compositions preserve the view into the central valley. Footer art gets modestly more vertical room to make the detail legible.

Only binary alpha is exported; runtime CSS continues to provide #00583B over the light page background or the existing dark accent #96D5B5 over #122724. Back-to-top stays outside the art. No photo, AI-generated input, extra runtime library, data change, or third-party browser asset request.

Desktop PNG: 25985 bytes. Mobile PNG: 9242 bytes. Standalone light/dark proofs saved locally. Production assets use new revision filenames to prevent stale image caches.
