# Retained specimen taxonomy recovery, adapter 1.2.0

MAIN implements this automated pathway under the existing autonomous research authorization. It does not claim human approval. The earlier exact-binomial and metadata-recovery branches remain supported; historical runs are unchanged.

The first evaluated scope is the 316 retained NYBG infraspecific inventory witnesses, using the licensed WCVP version 16 archive extracted 2026-06-04. The complete 1,448,984-row names export was indexed for these source components, every catalog name, and all linked accepted names and parents. A separate extraction check verified all 3,271 retained reference rows by physical row number, all fields and original line SHA. Both the compressed reference and inventory hashes are pinned; changed catalog identities or source witnesses require renewed review. This index is not complete for arbitrary names.

An exact authoritative full name and authorship, or an explicit source autonym parent, must resolve to an accepted taxonomic concept contained by one catalog concept. The source autonym path relies on the declared parent identity and Kew parent concept; it does not claim that Kew accepts the exact infraspecific name or rank. Accepted-concept ancestry is retained, so shared species ancestry cannot identify sibling subspecies as one another. Hybrids, misapplied names, unsupported authors, outside-catalog concepts and ambiguous targets remain held. See WCVP methodology at https://powo.science.kew.org/about-wcvp and Madrid Code Articles 25.1, 26.1 and 6.2 Note 1 at https://www.iaptglobal.org/_functions/code/madrid?cid=5405e94c-cfce-4e1c-9972-90eddb9fbf12. Nomenclature alone does not establish current taxonomic circumscription.

The adapter still validates complete raw specimen rows, audited stable identities, valid or explicitly missing dates, exact active county aliases, source geography, attribution and cultivation context. Seven individual context holds are documented in scripts/fixtures/wcvp-specimen-context-review-20260906-r4.json. Generalized map coordinates near a shoreline or county edge do not automatically contradict source county text. A campus, field station or lawn word alone does not establish cultivation.

Every accepted run preserves the original full source name, the mapped catalog name, the source row, the immutable reference profile, accepted concept and parent IDs, derivation route, and WCVP attribution. WCVP version 16 is CC BY 3.0, as declared in README_WCVP.xlsx cell A6; older mirrors with different licensing do not override that release. Isitusa selects and maps the data without implying Kew endorsement. NYBG specimen metadata remains under its separately reviewed CC0 terms.

The retained-artifact preflight reuses the full source identity audit, reevaluates the retained witnesses, and subtracts current determinations. It explicitly labels this as an inventory-subset review, not a new complete archive taxonomy screen. It creates zero source requests. Run npm run research:preflight:retained-taxonomy -- --as-of YYYY-MM-DD --output <new-cache-path>, then the existing retained-herbarium state-plan builder with --profile nybg and a new campaign identity. MAIN commits validated plans before source runs.

The evaluated trial contains 165 eligible witnesses, one existing present overlap and 164 net candidates across 32 states. These are candidate counts until immutable runs are integrated and national projections reconciled. They support historical recorded occurrence only; they do not establish occurrence in 2026, establishment, introduced status, absence or research completion.

Validation: npm run check:retained-specimen-taxonomy, existing retained-herbarium and specimen-metadata regressions, typecheck, and the retained preflight/state-plan trial. The new tests exercise every eligible retained witness and all seven context holds, reference/inventory/catalog changes, out-of-scope sources, original dates/names, attribution, missing modes, altered targets and raw witnesses, and mapping lineage.
