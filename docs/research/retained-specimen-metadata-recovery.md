# Retained preserved-specimen metadata recovery, adapter 1.1.0

MAIN implements this method under the user's autonomous national research authorization recorded in ops/national-research/receipts/authorizations/autonomous-national-research-20260906-r1.json. Review is automated and identified as machine-validated; this is not a claim of human review.

A trustworthy undated specimen can support documented historical county occurrence. The collection date remains null, source narrative remains retained, and the acquisition timestamp only records retrieval. These assertions do not establish present-day persistence, establishment, abundance, or countywide occupancy.

Recovery is opt-in. It requires the pinned licensed archive and occurrence-entry identities, an exact current determination baseline, a complete second-pass identity audit, one stable occurrence identifier or archive-bound core identifier, a retained complete raw row and its hash, an exact catalog taxon and active county match, and verified witness-set and preflight hashes. Extraction must follow acquisition and precede run start. The runner reseals a subset's witness-set hash. Historical 1.0.0 and 1.0.1 runs and the legacy parameter branch remain valid.

Harvard's CC BY 4.0 archive requires Harvard University Herbaria attribution. Record metadata and image access terms are distinct. The run retains the publisher rights holder, source locator, archive identity and raw license/access text; this method reproduces no specimen media. NYBG and Smithsonian use their pinned CC0 dataset profiles. TORCH's legacy CC0 path remains supported; its recovery path stays disabled until its separate CSV identity audit is evaluated.

The preflight and adapter reject explicit cultivation/captivity, uncertain taxonomy, unresolved geography, contradictory occurrence status, invalid/future dates and identity collisions. Review holds target individual raw-row hashes. Three Harvard witnesses explicitly indicate cultivation. Two further witnesses have unresolved experimental-station cultivation context or Calaveras/Amador county lineage. The reasons and original rows are preserved in scripts/fixtures/harvard-specimen-metadata-review-20260906.json. A held witness creates no absence or non-detection; another adequate witness for that pair may still qualify.

Darwin Core permits eventDate to contain an interval as well as a date-time. The recovery method currently has no evaluated interval projection and freshness contract. It records event-date-interval-requires-review, preserving the original value without treating every interval as malformed or reducing it to its first day. The diagnostic found valid-looking full and partial intervals alongside a reversed interval. None is newly accepted by this method. Existing dated evidence remains append-only and is not silently replaced. Source: [TDWG Darwin Core eventDate](https://dwc.tdwg.org/terms/#eventDate), inspected 2026-09-06.

Recovery plans accept a positive marginal gain without the legacy campaign's fixed 2000-pair threshold. Plans independently reconstruct the current national determined-pair hash, subtract already determined pairs, pin the source/assessment date, and retain archive-audit results. This is candidate admission; only integrated, compiled and reconciled unique pairs count as new determinations.

Before a recovery campaign: run the current source-coverage gate; set the exact baseline commit and pair hash; execute the complete preflight with --metadata-recovery and --as-of; create plans using an explicit --campaign; commit the reviewed plans; run registered adapters; verify immutable receipts; then compile and reconcile under MAIN. Shared generation and release remain sequential. Small batches can be combined for publication under the seven-day cadence and independently verified R2 budgets.
