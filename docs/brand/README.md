# isitusa brand kit

Current release: transparent vector v3, authorized September 29, 2026.
Name: isitusa. Website: isitusa.com. Both lowercase. Master color: #00583B.

The approved v2 artwork was traced online with Free SVG Online in B&W High mode.
The v3 SVG masters contain actual vector paths, one green fill, transparent
negative space and no embedded bitmap, font or external dependency. The v2
originals remain archived unchanged. v3 replaces the old opaque white artwork.

Use SVG for web and print; use the transparent PNG fallbacks for email and
systems without SVG support. Preserve proportions and allow clear space.
The site's dark theme displays the same transparent shapes in white for contrast.
The downloadable masters remain green. favicon.svg adapts to the browser theme.

Current files are under /brand/v3/. Versioned paths receive immutable caching;
future changes must use a new version. /favicon.ico, /site.webmanifest and
/isitusa-logo.png are compatibility endpoints that revalidate.

The email signature and participation-delivery template are prepared assets,
not authorization to send email or activate backend services. No external social
account is changed. Use must not imply endorsement, partnership or nonprofit
status. Historical reports retain their original branding. See /brand for files.
